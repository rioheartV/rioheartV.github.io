ダウンロード

⬇ MoveArt をダウンロード

版 2026.10.25.1 ・ zip 178 MB ・ Python などを入れる必要はありません

ダウンロードの前に、下の利用規約を読んでください。自己責任で使ってください。

ファイルが本物か確かめたい時の SHA256： bf695989e543fd948ec94767a97bd3ddaa4fe00eaa67805fc3fb2e8d4ac1ac2d

できること

  • 自分の PSD（レイヤー分けした絵）を取り込んで動かせる（レイヤーがそのままパーツになります）
  • カメラの顔トラッキングで頭・目・口が動く・マイクの声で口パク
  • 仮想カメラで OBS・配信・ほかのアプリにそのまま映せる（背景の色も選べます）
  • パラメータを振った状態でパーツを動かすと、その形がそのパラメータに保存される・揺れ物理
  • 録画・スクショ・PSD の書き出し・SmartPaint と連携して塗り直し

この版の顔トラッキングは 1 日 1 時間までです。読み込めるのは PSD と MoveArt のモデルだけです。

はじめかた

  1. ダウンロードした zip を右クリック →「すべて展開」で、デスクトップやドキュメントなど書き込める場所に展開します（zip の中から直接起動しないでください。Program Files の中には置かないでください）。
  2. 展開したフォルダの MoveArt.exe をダブルクリックします。
  3. 最初に利用規約が出ます。読んで同意すると始まります。
  4. キャラ選択の画面で「＋ キャラを追加…」を押し、自分の PSD を選びます。カードを押すとそのキャラで開きます。
  5. くわしい使い方は、アプリの「ヘルプ」→「📖 操作ガイド」にあります。

「WindowsによってPCが保護されました」と出た時

個人で作った無料のアプリには作者の電子署名が付いていないため、初めて起動する時にこの青い画面が出ます。 「詳細情報」→「実行」を押すと起動します（2 回目からは出ません）。

ダウンロードしたファイルが本物か確かめたい時は、PowerShell で次を打ち、上の SHA256 と同じかを見てください。

Get-FileHash .\MoveArt_2026.10.25.1.zip -Algorithm SHA256

モデルと設定の置き場所・消し方

  • 取り込んだキャラ・モデル：展開したフォルダの out\auto（キャラの一覧は data）
  • スクショ・録画：展開したフォルダの screenshots・recordings
  • 設定・利用時間の記録：%LOCALAPPDATA%\MoveArt
  • 新しい版に入れ替える時は、out と data のフォルダを新しいフォルダへ移してください。
  • 消す時は、展開したフォルダと %LOCALAPPDATA%\MoveArt を消してください。
